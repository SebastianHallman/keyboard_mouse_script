# Control your mouse with your keyboard

My bluetooth mouse on my Permobil wheelchair stopped working, leaving me without a mouse to use. This simple python script gives your keyboard mouse capabilities while numlock is enabled. Use WASD to move the mouse around and 1/2 to left/right click. Comes with a custom crosshair.

## How to run

- Clone the repo
- Activate a venv with the ```keyboard``` package installed or have the package in your global packages
- Run ```kb_mouse.py```

## Limitations

- Crosshair overlay does not show on secondary monitors
